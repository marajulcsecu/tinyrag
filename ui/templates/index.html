আসসালামু আলাইকুম! আমি আপনার কৃষি এআই সহায়ক (AgriRAG)

বাংলাদেশ ধান গবেষণা ইনস্টিটিউট (BRRI), বারি (BARI) ও কৃষি সম্প্রসারণ অধিদপ্তরের (DAE) প্রামাণ্য নির্দেশিকা ভিত্তিক

ধান, আলু, সবজি, ফল ও মসলা ফসলের রোগ-বালাই, পোকা দমন, অনুমোদিত বালাইনাশকের সঠিক মাত্রা এবং মাঠের আবহাওয়া সম্পর্কে নিচে লিখে অথবা মাইক্রোফোন বাটনে চাপ দিয়ে বাংলায় কথা বলে প্রশ্ন করুন।

ইঞ্জিন মোড ও সংযোগ সেটিংস (Local / Cloud API)

পিসি বা ফোনে র‍্যাম কম থাকলেও যেন দ্রুত উত্তর পাওয়া যায়, সেজন্য দুটি ইঞ্জিন মোড রয়েছে:

দ্রুত প্রিসেট:
মোবাইল ফোনে চালানোর উপায়:
  • USB বা হটস্পট: USB ডিবাগিং (`adb reverse tcp:8000 tcp:8000`) দিয়ে ফোনের ব্রাউজারে http://localhost:8000 অথবা মোবাইল হটস্পটে ল্যাপটপের IP ঠিকানায় ওপেন করুন।
  • ক্লাউড API মোড: উপরের ক্লাউড মোডে ফ্রি Gemini/Groq API Key দিলে ভারী লোকাল মডেল ছাড়াই তাৎক্ষণিক উত্তর পাবেন।
  • অ্যাপ ইনস্টল (PWA): ফোনের Chrome মেনু থেকে "Install App / Add to Home Screen" চাপলে এটি নেটিভ অ্যাপ হিসেবে ইনস্টল হবে।
