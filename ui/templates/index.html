আসসালামু আলাইকুম! আমি আপনার কৃষি এআই সহায়ক (AgriRAG)। 🌱

বাংলাদেশের ধান, আলু, সবজি, ফল ও মসলা ফসলের রোগ-বালাই, পোকা দমন, সঠিক বালাইনাশকের মাত্রা এবং আজকের মাঠের আবহাওয়া/মাটির আর্দ্রতা সম্পর্কে বাংলায় লিখে অথবা 🎤 মাইক বাটনে চাপ দিয়ে কথা বলে প্রশ্ন করুন। উত্তরটি আমি বাংলায় লিখে ও পড়ে শোনাব!

⚙️ ইঞ্জিন মোড ও মোবাইলে ব্যবহার (Hybrid Local / Cloud API)

আপনার পিসি বা ফোনে শক্তিশালী র‍্যাম না থাকলেও যেন AgriRAG ব্যবহার করতে পারেন, সেজন্য দুটি ইঞ্জিন মোড রাখা হয়েছে:

দ্রুত প্রিসেট:
📱 সাধারণ মোবাইল ফোনে চালানোর ৩টি উপায়:
  • উপায় ১ (একই Wi-Fi / হটস্পট): ল্যাপটপে API_HOST=0.0.0.0 bash run.sh চালিয়ে ফোনের ব্রাউজারে ল্যাপটপের IP ঠিকানায় ঢুকলে ২ জিবি র‍্যামের ফোনেও ভয়েস-টু-ভয়েস চলবে।
  • উপায় ২ (ক্লাউড API Key): উপরের ক্লাউড API মোড চালু করে ফ্রি Gemini/Groq API Key দিলে ভারী লোকাল মডেল ছাড়াই সুপার-ফাস্ট উত্তর পাবেন।
  • উপায় ৩ (মোবাইল অ্যাপ / PWA): ফোনের Chrome মেনু থেকে "Add to Home Screen / Install App" চাপলে এটি মোবাইল অ্যাপ হিসেবে ইনস্টল হয়ে যাবে।
